# 📝 Gestor de Tareas en Java (Proyecto de Repaso)

¡Hola! Este repositorio forma parte de mi proceso de repaso y puesta a punto de los fundamentos de **Java** y la **Programación Orientada a Objetos (POO)**. 

El objetivo de este proyecto es construir una aplicación funcional desde cero, aplicando conceptos clave que fui aprendiendo durante el curso pero llevándolos a la práctica de forma limpia y ordenada.

## 💡 ¿Qué conceptos practico en este proyecto?
* **POO Avanzada:** Uso de clases abstractas, herencia (`extends`), llamada a constructores con `super` y polimorfismo (`@Override`).
* **Estructuras de Datos:** Manejo de colecciones dinámicas como `ArrayList`.
* **Lógica y Control de Flujo:** Bucles (`while`, `for-each`) y menús interactivos con `switch-case`.
* **Entrada de Datos:** Uso de la clase `Scanner` por consola.

## 🛠️ Estructura del proyecto
* **`model`**: Contiene la clase base de las tareas y sus variantes (tareas de trabajo, personales, etc.) aplicando herencia.
* **`service`**: El "cerebro" o lógica que gestiona la lista de tareas (añadir, listar, completar, borrar).
* **`main`**: La interfaz por consola para que el usuario pueda interactuar con el menú.
